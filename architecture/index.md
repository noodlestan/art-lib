# Art Cli Architecture

## Overview

This directory contains architecture documentation for the Art Cli packages.

## Packages

### Lib Records

- **Canonical Name:** `@art-cli/lib-records`
- **Path:** `libs/records`
- **Purpose:** Generic record read/write modules for Art MD record files. Find, read, and filter Art MD record files across a search path, honoring gitignore and configured patterns.
